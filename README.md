# Bizland — Business Landing Page

A responsive business landing page built with semantic HTML, custom CSS, and Bootstrap 5.3.3. This project is a front-end practice project focused on responsive layouts, navigation, cards, and image-led sections.

## Features

- Responsive navigation with a mobile menu and dropdown
- Hero section with call-to-action links
- Four feature cards with custom inline SVG icons
- About section with supporting imagery and content
- Portfolio image cards
- Contact call-to-action and footer
- Responsive layouts for desktop, tablet, and mobile
- Hover states, keyboard focus styles, and reduced-motion support

## Technologies

- HTML5
- CSS3
- Bootstrap 5.3.3
- Google Fonts (Inter)
- Unsplash images

## Run locally

1. Download or clone this repository.
2. Keep `index.html`, `styles.css`, and `README.md` in the same folder.
3. Open `index.html` in a browser.

## Images and external resources

The page uses image URLs hosted by Unsplash and loads Bootstrap and Google Fonts from their CDNs. An internet connection is required for these resources. You can replace the image URLs in `index.html` with your own images at any time.

## Publish with GitHub Pages

1. Upload `index.html`, `styles.css`, and `README.md` to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then save.

## Before publishing

The Contact section uses `hello@example.com` as a demo email address. Replace it with your preferred contact address before sharing the site publicly. Portfolio content is sample content for this practice project.
